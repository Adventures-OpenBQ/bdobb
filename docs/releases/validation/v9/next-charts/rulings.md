# Financial and source decisions

## Acquisition and storage

- A qualifying backend receipt comes from the successful request, its exact route, parameters, selector and delivered rows. Each family revalidates its own closed metadata. The off-tab collector follows the same rule as mounted source cards. An explicit local acquisition must agree with its declared identities, units, dates, raw hazards and scope. Validation cannot independently authenticate the origin or completeness asserted by the file author.
- Raw contradictions survive aliases, filters, aggregation boundaries and multiple linked tables. Coordinate-only omission metadata can withhold eligibility. It carries no hidden amounts. Settings exports preserve the question and explicit pins. Attached files remain subject to the existing local-asset export guard. A portable source-free workspace needs a new File selection. This requires a manual step and prevents evidence from traveling as a setting.
- Latest means the latest compatible **acquired** observation. A missing explicit pin requires repair. Fundamentals L1 and the L2 adapter preserve the original successful fetch-completion time. A timestamp-less or chronologically inconsistent legacy cache record still supplies table rows. It cannot authorize a chart vintage or trigger a hidden refetch.
- A failure in one live source gates only the affected mode. Local prepared modes and other qualifying sources remain available. The exact AAPL daily EOD feed already supplies adjusted prices. The present historical adapter drops facts before normalization and the return consumer explicitly trusts only its documented local acquisition boundary. A route-qualified raw-aware adapter and paired tests could support a bounded one-listing window. Four adjacent closes alone give at most three returns, below the five-return minimum. No extra feed purchase follows from this adapter limitation.

## Rendering, regressions and remaining limits

- Source replacement uses persisted configuration across every validated ancestor. Backend tables resolve bound inputs through the existing card parameter rules and omit form fields from the GET. Each actual fetch owns its response and failure. A changed backend origin, resolved query, credentials or selector advances a private request generation. A clock-relative date that resolves differently is a different acquisition. Render keys receive only the generation. The shared key excludes retrieval counters, theme, title and geometry. A same-request refresh can retain completed data with its stale indication. Producer replacement also retires a result when validation refuses or holds the GET. Editing a Run-button source keeps the armed input available for a return to the same question. Executing the new question retires the previous request. HTTP header names are case-insensitive, while header values, cookie names and query credential names retain their exact meanings. Its serialization is memoized for linked charts and KPI cards. Capturing configurations on a dashboard edit costs work proportional to the dashboard and ancestry, independent of the number of observations.
- React StrictMode chart cleanup must distinguish a still-mounted graph from an obsolete instance. Native hierarchy teardown cancels listeners before a queued transition can touch a purged graph. Earlier known-size and hover failures remain reproducible with the retained opt-in worker and native-fill probes. [Reproduction commands](reproduce/README.md)
- Earlier grouped Chromium runs recorded 69/70 during overlay integration (a page reload during a news touch gesture, trigger unknown), 80/81 during revision integration (unguarded ETF theme poll), and 86/87 during market integration (a KPI dynamic module fetch failed before a geometry assertion). The news case passed isolated candidate and baseline reruns. The ETF assertion was guarded and reran with the same exact color. The KPI case passed an unchanged focused rerun. These historical outcomes remain separate from the final candidate sweep. The second backend correction subsequently exposed the same transient absent Plotly layout in two theme polls, for overlay and market map. The group result was 86/88, followed by 2/2 after those assertions waited for a connected layout with the exact expected color. The final verification record also identifies full-suite framework warnings and opt-in skips. [Verification](verification.md)
- The source-parser fixture coverage lives in the shared registry tests. It exercises the local import boundary. News hover polarity/color assertions were tightened during integration. No additional data acquisition, automatic snapshot collection, paid subscription, publication or deployment was part of this validation.
