# Day Chart drag edge scrolling
User requests scrolling past visible tiles while dragging. Extend existing pointer capture reorder: scroll only the widget's active layout axis when a dragged tile is held within 48px of that edge, with speed increasing toward the edge. Recompute the hovered drop tile as content moves beneath the stationary pointer. Stop immediately on release, cancellation, capture loss, unmount, or list/layout change. Preserve shared-list saving and selected symbol. Test both directions, stationary holds, center/outside positions, bounds and cancellation; publish and verify Vercel.
