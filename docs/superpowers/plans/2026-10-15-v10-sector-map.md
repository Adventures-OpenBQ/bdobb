# v10 Sector Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A live S&P 500 sector treemap card on the v10 example dashboard. Tile area is SPY's sector weight; tile colour is the sector SPDR ETF's day % change, served by live-grid.

**Architecture:** A pure module in openbq-docker live-grid, `app/sector_map.py`, owns the sector→ETF map, the weights fetch with its cache, and the figure builder. A thin `/sector_map` route in `app/main.py` renews leases, seeds any cold quotes, and returns the figure. A `chart` widget polls it every 15 s. bdobb registers Plotly's `treemap` trace and adds the card to the v10 example. `pnpm apps:sync` copies that example into od's `live-grid/apps.json`.

**Tech Stack:** Python 3 / FastAPI / pytest (live-grid); TypeScript / React / vitest / plotly.js 3.7.0 (bdobb).

**Spec:** `docs/superpowers/specs/2026-10-15-v10-sector-map-design.md` (this branch, commit 5434d28)

- Line: v10.0.0 in both repos. No point-release tags. Nothing is pushed, tagged or re-cut by this plan; placement is the user's call.
- Branches: `claude/v10-sector-map` off `origin/release/v10` in **Adventures-OpenBQ/bdobb** and **Adventures-OpenBQ/openbq-docker**.

## Review Focus

1. **Weights arrive as strings** (`"41.2029"`) on some EODHD responses. They must parse the same as floats. Pinned in Task 2 (`test_weights_accept_string_values`).
2. **A renamed or missing EODHD sector**, for example Morningstar renaming "Consumer Cyclicals", must give a 502 that names the missing sector, never a 10-tile map. Pinned in Task 2 (`test_missing_sector_raises_naming_it`) and Task 3 (`test_route_502_when_weights_fail`).
3. **A persistent weights failure must not hit EODHD every 15 s per open card**, given the quota and the 402→502 history. The failure is cached for 5 minutes. Pinned in Task 2 (`test_failure_is_cached_briefly`).
4. **No ETF has a quote yet** (cold start, weekend): the map still draws all 11 tiles, grey and "n/a", and the colour bounds don't crash on an empty list. Pinned in Task 2 (`test_all_changes_missing_draws_grey`).
5. **An ETF already in the quote table must not trigger a REST call**, or every poll would cost 11 vendor calls. Pinned in Task 3 (`test_route_seeds_only_cold_etfs`).

## Rulings I made (not in the spec)

- A failed weights fetch is cached for 300 s, so the 502 repeats without a vendor call until the cache expires.
- A tile with no change uses colour value 0. That is the grey midpoint of the scale, which is how "drawn grey" is implemented, because Plotly's handling of `null` in treemap `marker.colors` is undefined.
- The colorscale is `#d32f2f` → `#555555` → `#2e7d32`.

```python
# Copyright 2026 SecretoftheUniverse.com LLC. Licensed under the Apache License, Version 2.0.
# SPDX-License-Identifier: Apache-2.0

"""S&P 500 sector map: SPY's sector weights x each sector SPDR's day change.

Weights come from EODHD's SPY.US fundamentals, which use Morningstar sector
names; the ETFs follow GICS. The 11 buckets line up by name, but individual
companies can sit in different buckets, so this is a teaching map, not an
index replica.
"""

import logging
import math
import time
from typing import Any

log = logging.getLogger(__name__)

# EODHD (Morningstar) sector name -> SPDR sector ETF. Checked against the live
# SPY.US response on 2026-10-15.
SECTOR_ETFS: dict[str, str] = {
    "Technology": "XLK",
    "Financial Services": "XLF",
    "Healthcare": "XLV",
    "Consumer Cyclicals": "XLY",
    "Communication Services": "XLC",
    "Industrials": "XLI",
    "Consumer Defensive": "XLP",
    "Energy": "XLE",
    "Utilities": "XLU",
    "Real Estate": "XLRE",
    "Basic Materials": "XLB",
}

_FILTER = "ETF_Data::Sector_Weights"
_TTL = 24 * 3600.0
_NEG_TTL = 300.0  # a failing vendor is retried every 5 min, not every 15 s poll
_COLORSCALE = [[0.0, "#d32f2f"], [0.5, "#555555"], [1.0, "#2e7d32"]]

# "weights" -> (dict | WeightsUnavailable, expiry on the monotonic clock)
_cache: dict[str, tuple[Any, float]] = {}


class WeightsUnavailable(Exception):
    """SPY's sector weights could not be read; the route answers 502."""


def _reset_cache_for_tests() -> None:
    _cache.clear()


def _read(resp: Any) -> dict[str, float]:
    if not isinstance(resp, dict):
        raise WeightsUnavailable("SPY.US sector weights: unexpected response")
    weights: dict[str, float] = {}
    for name in SECTOR_ETFS:
        try:
            w = float(resp[name]["Equity_%"])
        except (KeyError, TypeError, ValueError):
            continue
        if math.isfinite(w) and w > 0:
            weights[name] = w
    missing = [name for name in SECTOR_ETFS if name not in weights]
    if missing:
        raise WeightsUnavailable("SPY.US sector weights missing: " + ", ".join(missing))
    return weights


def fetch_weights(client, now: float | None = None) -> dict[str, float]:
    """Sector name -> % of SPY. Raises WeightsUnavailable; never invents weights."""
    now = time.monotonic() if now is None else now
    hit = _cache.get("weights")
    if hit and hit[1] > now:
        if isinstance(hit[0], WeightsUnavailable):
            raise hit[0]
        return hit[0]
    try:
        weights = _read(client.get_fundamentals_data(ticker="SPY.US", filter=_FILTER))
    except WeightsUnavailable as exc:
        _cache["weights"] = (exc, now + _NEG_TTL)
        raise
    except Exception as exc:  # noqa: BLE001 - any vendor failure is a 502, not a crash
        err = WeightsUnavailable(f"SPY.US sector weights: {exc}")
        _cache["weights"] = (err, now + _NEG_TTL)
        raise err from exc
    _cache["weights"] = (weights, now + _TTL)
    return weights


def build_sector_figure(weights: dict[str, float], changes: dict[str, float | None]) -> dict:
    """One treemap: area = weight, colour = day % change (changes are fractions)."""
    labels, values, colors, text = [], [], [], []
    known: list[float] = []
    for name, etf in SECTOR_ETFS.items():
        frac = changes.get(etf)
        pct = frac * 100 if isinstance(frac, (int, float)) and math.isfinite(frac) else None
        w = weights[name]
        labels.append(name)
        values.append(w)
        if pct is None:
            colors.append(0)  # the scale's grey midpoint
            text.append(f"{etf}<br>{w:.1f}% · n/a")
        else:
            known.append(abs(pct))
            colors.append(pct)
            text.append(f"{etf}<br>{w:.1f}% · {pct:+.2f}%")
    bound = max(known + [1.0])
    return {
        "data": [
            {
                "type": "treemap",
                "labels": labels,
                "parents": [""] * len(labels),
                "values": values,
                "branchvalues": "total",
                "text": text,
                "textinfo": "label+text",
                "hoverinfo": "label+text",
                "marker": {
                    "colors": colors,
                    "colorscale": _COLORSCALE,
                    "cmid": 0,
                    "cmin": -bound,
                    "cmax": bound,
                    "showscale": True,
                },
            }
        ],
        "layout": {
            "title": {"text": "S&P 500 sectors — weight × day change"},
            "margin": {"l": 10, "r": 10, "t": 40, "b": 10},
            "template": "plotly_dark",
        },
    }
```

```python
    @app.get("/sector_map")
    async def sector_map():
        """S&P 500 sector treemap: SPY weights x sector-ETF day change.

        The ETFs reach the feed through leases, so this card never opens a
        second EODHD socket; a 15 s poll keeps renewing them, and the sweeper
        drops them once nobody asks.

        etfs = list(SECTOR_ETFS.values())
        leases.renew(etfs, now=asyncio.get_running_loop().time())
        client = _seed_client()
        try:
            weights = await asyncio.to_thread(fetch_weights, client)
        except WeightsUnavailable as exc:

            return JSONResponse({"data": [], "layout": {"title": {"text": f"Sector map: {exc}"}}},

        if cold:
            await asyncio.to_thread(quotes.seed, cold, client)
        changes = {s: quotes.rows.get(s, {}).get("change_percent") for s in etfs}
        return JSONResponse(build_sector_figure(weights, changes))
```
