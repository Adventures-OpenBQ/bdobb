> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Document clean v6 accurately in the in-app Help, the user guide and the v6 reference manual, record provenance, and produce the final gate and live-integration receipts on one tree.

**Architecture:** Help pages are Markdown under `src/help/guide/` (Reference Manual) and `src/help/topics/` (Quick Help), enforced by `src/help/guide.test.ts` and `src/help/index.test.ts`; screenshots come only from `pnpm help:shots`. Donor help is hand-ported hunk by hunk where the manifest says ADAPT, with BDOBB naming and `<your-tailnet>` placeholders. Verification runs every repo gate once on the final tree, builds a QA-identified native bundle, checks v5→v6 migration and v6→v5 rollback on QA profiles, and runs the live Rita gate that fails on any skip.

**Tech Stack:** Markdown, Vitest, Playwright (`scripts/help-shots.mjs`), Tauri CLI, Cargo, bash/curl.

**Spec:** `docs/superpowers/specs/2026-10-07-bdobb-clean-v6-client-design.md` (sections Help, Approach step 7, Verification 1–2). Prerequisites: Part A and Part B plans in `docs/superpowers/plans/` complete and green.
