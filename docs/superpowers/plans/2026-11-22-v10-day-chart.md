# Day Chart Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Follow TDD and independent review.

**Goal:** Implement and deploy the v10 Day Chart horizontal intraday tile strip.
**Architecture:** Live-grid owns bounded day snapshots and logo retrieval; a small frontend strip renders visible/nearby tiles and uses existing dashboard symbol-group bindings. Public traffic retains the gateway and Vercel authenticated doors.
**Tech Stack:** Python/FastAPI, existing EODHD/history infrastructure, React/TypeScript, small SVG line charts, Node gateway/Vercel.
**Spec:** ../specs/2026-11-22-v10-day-chart-design.md

## Global Constraints

- v10 only, no v12/BUSL implementation copied; use the recovered one-based list contract.
- Symbols CSV or existing symbol parameter-group binding. Preserve positional duplicates, deduplicate acquisition. Blank explicitly clears membership.
- 15s refresh, current or latest completed session, honest history/source/coverage; no fabricated accepted q cursor or quote-derived line points.
- Tile headline and previous-close basis correspond to the plotted session. Never mix postmarket quote with regular-session line without a separate label.
- Authenticated fixed-route logo proxy; no arbitrary upstream URL, no broad CSP relaxation.
- Existing BTC chart, quote stream, user dashboard and unrelated v12 changes remain intact.

## Frozen API

GET `/day_charts?symbol=AAPL,MSFT` max20 unique symbols per request (50 entries in widget; client batches visible/nearby symbols). Response `{schema_version:1,tiles:[...]}`. Each tile:
`{symbol,name,logo_path,session:{date,timezone,label,status},previous_close,price,change,change_percent,points:[{time,value}],as_of,status,source,coverage,error_code?}`.
- `time` UTC ISO, values finite numeric or null, `change_percent` percentage points.
- `status`: ok/partial/empty/error; safe per-tile error. Session status open/closed/unknown; timezone IANA. Honest nulls for unavailable values.
- `source`: eodhd for initial provider-history snapshot; coverage identifies actual first/last bar, not an invented tape cursor.
- `logo_path`: `/symbol_logo?symbol=AAPL` or null, never a credential-bearing remote URL.
- GET `/symbol_logo?symbol=AAPL` serves bounded approved raster bytes from EODHD metadata. Relay rewrites base path at frontend; no raw external image URL required.
- Request deadline20s, upstream work bounded4, shared15s cache and bounded in-flight/cache entries, response2MiB, history <=14calendar days/10000bars. Partial coverage explicitly reported.
