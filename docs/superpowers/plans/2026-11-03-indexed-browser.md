Keep the production createResultStore clone boundary for ordinary calls.

Guard: enabled schema1 analytical tables, excluding Statement and split-only/no-row layouts; default reconcileMissing=true, no previous namespace or proven-absent overrides; unchanged definition exceptsorting/runtime; same input/widget revision and strictly newer model/output. Freshness diagnostics must be included in canonical diagnostic metadata as well as normal publication context.

Generated diagnostics, outstanding transfers/messages and other worker/global allocations are not bounded by these estimates. These limitations remain gates before production.
