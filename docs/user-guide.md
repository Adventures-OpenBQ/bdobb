# BDOBB User Guide — v5 Development Candidate

V5 adds workspaces and a financial Statement view to the inherited v4 core improvements, including reusable version-pinned Statement templates.

1. Connect an OpenBB-compatible backend, validate it and open a reference App.
2. Use tables, analytical Pivot, date expressions, trading calendars, provider keys and docked Parameters as described in the v4 manual.
3. Create a workspace from the left rail, choose Full Screen or Laptop and assign dashboards. Each panel has its own tabs and controls.
4. Use Arrange to adjust panels; Done saves, Cancel discards the draft. Save layout as… stores reusable geometry without dashboard contents.
5. Choose Statement on a supported financial table to show sections and supplied fiscal periods. Fold sections, inspect the ordinary Table and export completed line-item rows.
6. Save locally or export BDOBB-compatible apps.json for the appropriate v3/v4/v5 profile. Workspace arrangements, dropped-file bytes and credentials require their separate storage/transfer paths.

See the [v5 reference manual](reference-manual/v5/README.md), [v4 reference manual](reference-manual/v4/README.md) and [v3 onboarding](reference-manual/v3/README.md). In-app Quick Help and Reference Manual include Workspace and Statement walkthroughs.

Optional User Settings storage on a server (Settings ▸ General ▸ User Settings) syncs display settings with a Workspace connection or a backend serving the Workspace settings API. It does not synchronize dashboards or workspace arrangements.

This is an isolated development candidate. Final v4 reconciliation and cumulative v5 qualification are pending; nothing has been published or tagged.
