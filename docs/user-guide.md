# Start using BDOBB v3.0.0

1. Open **Connections**, add your OpenBB-compatible backend URL, choose **Test**, then **Add**.
2. Choose **Apps** in the rail and **Open** a backend-supplied app, or use **Widget Library** to add individual widgets.
3. Edit a card's parameters. Linked numbered groups update their member cards together. Use **Run** when the card offers it; otherwise committed changes fetch automatically.
4. Use **Refresh**, **↻**, or **⌘R** when you want another answer. Configure numeric automatic refresh in **Settings ▸ General**; cron schedules are deferred.
5. Export through the dashboard-row menu. Choose **BDOBB-compatible** to preserve ordinary names/table state, or **OpenBB** for the plain app shape. Transfer local data files separately.

Open **Help ▸ Quick Help** for short topic instructions and **Help ▸ Reference Manual** for the longer guide. The [standalone v3 reference manual](reference-manual/v3/README.md) explains app conflicts, groups, settings, exports, and troubleshooting.

Analytical Pivot arrives in v4. Multi-dashboard workspaces and Statement arrive in v5. Optional User Settings storage on a server syncs display settings with a Workspace connection or a backend serving the Workspace settings API; it does not synchronize dashboards.
