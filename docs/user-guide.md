# Start using BDOBB v4.0.0

1. Connect your backend, then open a dashboard from Apps or add widgets from the library.
2. Use linked groups, Run and numeric refresh as in the qualified v3 desktop. Cron remains deferred.
3. Open Pivot for analytical categories, independent measures, formulas and Page filters. Inspect partial-data and provider hints.
4. Try Date expression and Period echo to verify relative dates, exchange sessions and fiscal periods. Dock a card’s Parameters and choose whether its values appear on the titlebar.
5. Save locally or export BDOBB-compatible apps.json to retain v4 model, links, calendar and panel choices. Plain OpenBB export omits those additions. Local-file bytes and credentials do not travel.

The [v4 reference manual](reference-manual/v4/README.md) explains the new controls and persistence boundary. The [v3 manual](reference-manual/v3/README.md) remains available for reference onboarding. In-app Quick Help and Reference Manual provide topic walkthroughs.

V4 is a local candidate under qualification. Reusable Statement templates are core v4 tools under Pivot → Saved → Statement template. Workspace layouts and generic Statement presentation arrive in v5; optional User Settings storage on a server syncs display settings with a Workspace connection or a backend serving the Workspace settings API, and does not synchronize dashboards.
