## Delivered API and ownership

`types.ts` adds descriptors without changing any existing TableExecutor/LocalWorkerExecutor signature. `ExecutionProvider.open(SourceBinding, SessionOptions)` negotiates protocol 1 and returns a ProviderSession with immutable capabilities, opaque session/source-snapshot identities and a result interface. Local binding carries `{kind:'local', input:WidgetDataset, inputRevision}`; remote binding carries only `{kind:'remote', sourceId, snapshotId}`. SessionOptions supplies widget identity, explicit locale, requested protocol version and optional acquisition AbortSignal.

The common result interface excludes registerInput, importFile and inputSchema. Local acquisition/schema remain on LocalWorkerExecutor. `createLocalExecutionProvider` requires an executor factory; the factory receives captured SessionOptions. Task 10 must supply the real `createRustExecutor`/Web Worker path and honor locale. This module performs no Wasm execution or analytical calculation on the main thread and does not choose a default executor. Existing TypeScript default/rollback remains unchanged.

Provider publication creates a new opaque resultId only after a successful apply, uses the validated returned revision and binds all calculated reads/export pulls to that published revision. Refused apply leaves the prior result identity and data usable. Source revision/widget coordinates are captured before asynchronous acquisition; caller mutation cannot change the binding or label a successful response with another revision. Authoring previews/binding/member-domain remain source-bound and may precede publication; they carry source ownership without inventing a calculated resultId. AbortSignal and disposal retain the executor lifecycle; exports check snapshot/result validity before and after each pull and close the iterator on settlement.

`providerCapabilities.ts` contains declaration-only preflight, immutable local capability defaults and structured ProviderContractError. It checks saved definition versions, explicit aggregations and nested formula calls, formula scopes/member selectors, grouping/splits, fiscal/Statement requirements, checklists/result filters, runtime parameters and selection before invoking apply. Optional result capabilities refuse instead of falling back. Statement compilation requires sum, not an unused last aggregation. The focused native `provider_contract::preflight` consumes the existing typed CapabilityDeclaration for protocol/definition versions, explicit aggregations/nested functions, fiscal and selection. Feature-grained provider declarations are enforced at the TypeScript provider boundary; a future native server adapter must also enforce the full ProviderCapabilities feature contract.

Counts match existing native wire variants: exact, estimated, unknown and snapshotExpired. `tableExecutorAdapter` preserves existing renderer numeric signatures only for exact nonnegative safe integers. It explicitly refuses unknown/estimated counts and expired counts at top-level, sibling and child levels, including estimated zero; it never derives counts from fetched pages or substitutes exact zero. Other evidence/selection counts remain exact in this version; a provider unable to supply them must refuse those operations. Adapter registerInput refuses source rebinding: open a new provider session instead. Snapshot expiry is a structured SNAPSHOT_EXPIRED error with the opaque sourceSnapshotId, and cannot become a successful empty page.
